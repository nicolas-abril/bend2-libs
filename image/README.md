# gralha-image

Premultiplied RGBA colors and square quadtree pixel buffers (`Picture`),
where uniform tiles share one color. The common output of the PNG and JPEG
decoders.

    import gralha-image@0.1.0.1/image.bend as Img

Main entry points: `Color`, `rgba`, `clear`, `Picture`, `picture.blank`,
`pixels.get`, `pixels.set`, `picture.depth`.

Depends on: gralha-text-scan.
